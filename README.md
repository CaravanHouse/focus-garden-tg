# Сад фокуса: Telegram Mini App + бот

[![CI](https://github.com/CaravanHouse/focus-garden-tg/actions/workflows/ci.yml/badge.svg)](https://github.com/CaravanHouse/focus-garden-tg/actions/workflows/ci.yml)

Таймер продуктивности внутри Telegram. За каждую рабочую сессию вырастает дерево, а бот присылает сообщение и ведёт рейтинг лесников.

**Что показывает клиенту:** мини-апп + бот + сервер, проверка подписи Telegram, уведомления, рейтинг.

## Как это работает
- Мини-апп на React стартует сессию на сервере, сервер запоминает время окончания.
- Закрыли приложение и не вернулись: через 20 секунд после конца таймера бот напомнит в чате.
- Дерево засчитывается, только если время реально вышло (проверка на сервере).
- Активная сессия переживает закрытие мини-аппа: вернулись, и таймер на месте.
- Все запросы к API подписаны Telegram (`initData`), подпись проверяется на сервере.

## Запуск
```bash
npm install
cp .env.example .env     # впишите BOT_TOKEN и WEBAPP_URL
npm run build            # собирает мини-апп
npm start                # бот + API + раздача мини-аппа
```
Для проверки только интерфейса в браузере: `DEV_NO_AUTH=1`, потом `npm run dev:server` и `npm run dev:web`.

## Подключение в Telegram
1. Создайте бота в @BotFather, токен в `.env`.
2. Выложите проект на Railway (см. ниже) или любой хостинг с Node.js, адрес в `WEBAPP_URL`. Можно вставить его как есть, без `https://`: схему сервер допишет сам.
3. При запуске бот сам настроит кнопку меню «Сад» и команды `/me`, `/top`.

## Проверка
`npm test` проверяет подпись initData, правила засчёта деревьев и защиту API.

## Деплой на Railway
1. **New Project → Deploy from GitHub** → этот репозиторий. Команды сборки и запуска, health check (`/health`) и автоперезапуск уже описаны в `railway.json`.
2. **Подключите Volume** с путём `/data`. Без него деревья и рейтинг стираются при каждом деплое.
3. **Variables:** `BOT_TOKEN`, `WEBAPP_URL` (адрес из **Settings → Networking → Generate Domain**), `DATA_DIR=/data`. `PORT` Railway задаёт сам.
4. Оставьте **1 реплику**: данные лежат в JSON-файле, несколько копий сервера затрут друг друга.

`DEV_NO_AUTH=1` на Railway сервер не запустит: с ним любой может пользоваться API без проверки Telegram. Для каждого проекта нужен **свой бот** в @BotFather: один токен в двух проектах даёт ошибку 409 Conflict.

## Данные
Деревья, рейтинг и активные сессии хранятся в JSON-файлах в папке `DATA_DIR` (по умолчанию `./data`). Напоминание о сессии приходит один раз и не повторяется после перезапуска сервера. При большой нагрузке переходите на PostgreSQL.
